# TECHFEST 2026 - 3D Interactive Website

This is a 3D interactive website created for TechFest 2026.

## Features

* Interactive 3D background
* 3D animations
* Mouse interaction
* Scroll animations
* Interactive event cards
* Futuristic design
* Mobile responsive

## Events

* AI Arena
* Robot Rumble
* Cyber Verse
* Innovate X

## Technologies

HTML, CSS, JavaScript, Three.js and Vite.

## How to Run

1. Open the project folder.
2. Run `npm install`
3. Run `npm run dev`
4. Open the URL shown in the terminal.

## Project Structure

`index.html` — Main webpage
`srcmain.js` — 3D effects and interactions
`srcstyle.css` — Website styling
`package.json` — Project dependencies
